# Harsh Sharma // Portfolio System

A GTA-inspired developer portfolio built to feel more like a game than a traditional website.

🌐 Live: https://gtabasedharsh.vercel.app/

## About

This portfolio was designed around a game-like interface instead of a conventional developer portfolio. It combines interactive UI, cinematic transitions, live HUD elements and full-screen sections to present my work in a more personal way.

## Built With

- Astro
- TypeScript
- JavaScript
- GSAP
- HTML & CSS

## Features

- GTA-inspired interface
- Interactive navigation
- Live HUD elements
- Animated transitions
- Responsive design
- Project and experience sections
- Configurable content system
- Static deployment

## Why I Built It

I wanted my portfolio to show more than just a list of skills and projects. The website itself is meant to represent how I approach development: experimental, interactive and focused on creating experiences.
